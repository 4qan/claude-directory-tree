## Visual Hierarchy

Primary focal point: tree artifact list. Secondary: detail panel. Tertiary: toolbar.

The tree always owns the most horizontal space. The detail panel slides in only when an artifact is selected and never obscures the tree. Toolbar elements (search, type filter) are visually subordinate — smaller text, no fill background in default state.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge padding |
| sm | 8px | Tree item horizontal padding (`px-2`), compact button gaps |
| md | 16px | Toolbar/panel internal padding, form field spacing |
| lg | 24px | Side panel header padding, section breaks |
| xl | 32px | Panel max-width gutters |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Tree item row height: 28px (`h-7`) — matches existing Phase 2 tree rows exactly
- Context menu item height: 32px (`h-8`) — standard touch/click target for menu items
- Toast height: 40px minimum — enough for single-line message + dismiss

Source: TreeItem.tsx (`h-7`, `px-2`, `gap-2`), button.tsx size variants

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (normal) | 1.5 |
| Label | 12px (`text-xs`) | 400 (normal) | 1.4 |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Caption | 10px (`text-[10px]`) | 400 (normal) | 1.0 |

Notes:
- Body (`text-sm`, weight 400) is the default for all artifact names and panel content — matches existing TreeItem leaf rendering
- Label (`text-xs`, weight 400) is for metadata: scope path, artifact type in detail panel
- Heading (`text-base`, weight 600) is for panel section headers and context menu group labels only
- Caption (`text-[10px]`, weight 400) is for existing MCP scope and plugin enabled/disabled badges — do not change
- No new font sizes introduced; all four roles are already present in the Phase 2 codebase
- Two weights only: 400 (normal) for body/label/caption, 600 (semibold) for heading

Source: TreeItem.tsx class names, button.tsx (`text-sm font-medium`), 03-CONTEXT.md

## Color

All values are CSS custom property references. Resolved hex depends on light/dark mode. Both modes are declared in App.css.

| Role | CSS Variable | Light mode approx | Dark mode approx | Usage |
|------|-------------|-------------------|------------------|-------|
| Dominant (60%) | `hsl(var(--background))` | #ffffff | #0a0a0f | Main app background, tree panel background |
| Secondary (30%) | `hsl(var(--muted))` | #f4f4f6 | #27272a | Hover state on tree rows, toolbar background, side panel background |
| Accent (10%) | `hsl(var(--primary))` | #17171a | #fafafa | Selected artifact row highlight, focused keyboard row ring |
| Destructive | `hsl(var(--destructive))` | #ef4444 | #7f1d1d | Move operation (destructive), conflict Replace File button, toast error state |

Accent reserved for:
1. Selected tree row background (single-click selection state)
2. Focused row keyboard outline ring (`focus-visible:ring-ring/50`)
3. Context menu item active/hover state

Do NOT use accent for: navigation labels, headings, icons in default state, or any element that is always visible. Accent is a state indicator, not a brand color.

Second semantic colors (already established in Phase 2 — maintain, do not add new ones):
- Blue (`bg-blue-100 text-blue-700`): MCP project scope badge
- Amber (`bg-amber-100 text-amber-700`): MCP local scope badge
- Purple (`bg-purple-100 text-purple-700`): MCP user scope badge
- Green (`bg-green-100 text-green-700`): Plugin enabled badge
- Zinc (`bg-zinc-100 text-zinc-500`): Plugin disabled badge

Source: App.css CSS custom properties, TreeItem.tsx badge color classes

## Interaction Contracts

### Click / Double-click (source: 03-CONTEXT.md decisions)

| Target | Single-click | Double-click |
|--------|-------------|--------------|
| Leaf artifact | Select + show detail panel | Open in system editor (POST /api/open) |
| Scope node | Expand/collapse (existing) | Same as single-click |
| Category node | Expand/collapse (existing) | Same as single-click |

### Context menu (source: 03-CONTEXT.md decisions)

| Target | Menu items |
|--------|-----------|
| Leaf artifact | Open in Editor / Copy to... / Move to... / [separator] / Promote to Global OR Demote to Project |
| Scope node | Open Folder |
| Category node | No context menu |

Context menu opens on: right-click, Shift+F10 (keyboard), Menu key (keyboard).
Context menu closes on: Esc, click outside, action selected.

Flyout "Copy to..." / "Move to...":
- Appears on hover/arrow-right on parent item
- Lists all registered projects as target options
- Each project item shows project name (directory basename)
- If project count exceeds 8, show an inline type-to-filter input at top of flyout

### Keyboard navigation (source: 03-CONTEXT.md decisions)

| Key | Action |
|-----|--------|
| Arrow Up / Down | Navigate tree rows |
| Arrow Right | Expand folder / enter flyout submenu |
| Arrow Left | Collapse folder / exit flyout submenu |
| Enter | Select artifact (shows detail panel) |
| Enter (on already-selected leaf) | Open in editor |
| Esc | Close context menu / close detail panel / return focus to tree |
| Shift+F10 or Menu key | Open context menu on focused item |
| Cmd+C | Copy selected artifact to clipboard state |
| Cmd+V | Paste artifact into currently focused scope |
| Cmd+F | Jump focus to search input |
| Tab | Cycle focus zones: search input -> type filter -> tree |

### Selection state styling

Selected leaf row:
- Background: `bg-primary/10` (10% primary — subtle highlight, not full accent fill)
- No border needed; background is sufficient visual indicator
- Focus ring on keyboard navigation: `ring-2 ring-ring/50 outline-none`

### Detail panel

| State | Behavior |
|-------|---------|
| Nothing selected | Panel hidden; tree takes full width |
| Artifact selected | Panel slides in from right; tree shrinks to fill remaining space |
| Panel width | 280px fixed; tree is fluid |
| Panel transition | `transition-all duration-150` — matches existing tree expand/collapse timing |

Panel content:
1. Artifact name (heading, `text-base font-semibold`)
2. Type label with icon (same icon from ICON_MAP, `text-sm text-muted-foreground`)
3. Scope: global or project name (`text-xs text-muted-foreground`)
4. Path: absolute path, truncated with ellipsis (`text-xs text-muted-foreground font-mono`)
5. Divider
6. Description: frontmatter `description` field if present; else first non-frontmatter paragraph; else "No description available."

### Toast notifications

| Event | Message | Duration |
|-------|---------|----------|
| Copy success | "Copied [artifact name] to [project name]" | 3s auto-dismiss |
| Move success | "Moved [artifact name] to [project name]" | 3s auto-dismiss |
| Promote success | "Promoted [artifact name] to global scope" | 3s auto-dismiss |
| Demote success | "Demoted [artifact name] to [project name]" | 3s auto-dismiss |
| Open in editor | No toast — silent (OS handles feedback) | — |
| Operation error | "Failed to [action]: [reason]. Check terminal for details." | 6s, no auto-dismiss |

Toast position: bottom-center of viewport. Stack from bottom upward if multiple.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (context menu open) | "Open in Editor" |
| Primary CTA (copy) | "Copy to..." |
| Primary CTA (move) | "Move to..." |
| Promote action | "Promote to Global" |
| Demote action | "Demote to Project" |
| Open folder (scope menu) | "Open Folder" |
| Detail panel empty | "Select an artifact to see its details." |
| Description fallback | "No description available." |
| Conflict dialog heading | "File already exists" |
| Conflict dialog body | "[artifact name] already exists in [project name]. Do you want to replace it?" |
| Conflict dialog cancel | "Keep Original" |
| Conflict dialog confirm | "Replace File" |
| Move error (conflict cancel) | Operation aborted, no toast shown |
| Operation error toast | "Failed to [copy/move/promote/demote]: [server error message]. Check terminal for details." |
| Clipboard empty paste | No action, no toast (silent fail — nothing to paste) |

Destructive actions:
- Move (destructive to source): No confirmation dialog — move is reversible via Cmd+Z (out of scope) or re-move. Source artifact is gone after move.
- Replace on conflict: Confirmation dialog with "Replace File" button (destructive variant, red) + "Keep Original"
- Promote/Demote: No confirmation — low-risk operations, easily reversed
