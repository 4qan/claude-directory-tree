**Create `client/src/components/ConflictDialog.tsx`:**

Modal overlay dialog for file conflicts.

```tsx
import { Button } from '@/components/ui/button';

interface ConflictDialogProps {
  artifactName: string;
  targetProject: string;
  onKeep: () => void;     // "Keep Original" -> cancel
  onReplace: () => void;  // "Replace File" -> overwrite
}

export function ConflictDialog({ artifactName, targetProject, onKeep, onReplace }: ConflictDialogProps) {
  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center">
      <div className="absolute inset-0 bg-black/50" onClick={onKeep} />
      <div className="relative bg-background border border-border rounded-lg shadow-xl p-6 max-w-sm w-full mx-4">
        <h3 className="text-base font-semibold mb-2">File already exists</h3>
        <p className="text-sm text-muted-foreground mb-4">
          {artifactName} already exists in {targetProject}. Do you want to replace it?
        </p>
        <div className="flex justify-end gap-2">
          <Button variant="outline" size="sm" onClick={onKeep}>Keep Original</Button>
          <Button variant="destructive" size="sm" onClick={onReplace}>Replace File</Button>
        </div>
      </div>
    </div>
  );
}
```

**Create `client/src/components/ContextMenu.tsx`:**

Custom Tailwind dropdown with flyout submenu. Positioned using `getBoundingClientRect()` with viewport edge flipping (if bottom + menuHeight > window.innerHeight, render above).

Props:
```typescript
interface ContextMenuProps {
  x: number;              // mouse clientX
  y: number;              // mouse clientY
  nodeKind: 'leaf' | 'scope' | 'category';
  data: TreeNodeData;     // the node data
  scopes: ScopeNode[];    // all scopes (for flyout project list)
  onClose: () => void;
  onRefresh: () => void;  // trigger tree refresh after operation
}
```

**Menu structure by nodeKind:**

For `leaf`:
- "Open in Editor" (icon: ExternalLink) -- calls `openInEditor(data.absolutePath)`
- "Copy Path" (icon: Clipboard) -- calls `copyPathToClipboard(resolveCopyPath('leaf', data))`, toast "Path copied to clipboard"
- Separator
- "Copy to..." (icon: Copy) -- hover opens flyout with project list. **Disabled** if `BLOCKED_TYPES.includes(data.type)`, show tooltip "Managed in config file".
- "Move to..." (icon: ArrowRight) -- hover opens flyout. **Disabled** if blocked.
- Separator
- "Promote to Global" (if `data.scope === 'project'`) OR "Demote to Project" (if `data.scope === 'global'`) -- icon: ArrowUpCircle/ArrowDownCircle. **Disabled** if blocked.
  - Demote also opens flyout to select target project.

For `scope`:
- "Open Folder" (icon: FolderOpen) -- calls `openInEditor(data.rootPath)`
- "Copy Path" (icon: Clipboard) -- copies `data.rootPath`

For `category`:
- "Copy Path" (icon: Clipboard) -- copies resolved type subdirectory path. Resolve using: find the parent scope's rootPath from scopes array (category id starts with scope id), then append type dir.

**Flyout submenu:**
- Appears on hover/arrow-right on "Copy to...", "Move to...", or "Demote to Project"
- Lists all scopes where `scope.scope === 'project'` (exclude global for copy/move targets)
- Each item shows `scope.label` (project name)
- If more than 8 projects, show an `<input>` at top of flyout for type-to-filter
- Flyout positioned to the right of the parent menu item. If would overflow right viewport edge, position to the left.

**Operation execution flow (on project selection in flyout):**

1. Determine `destinationDir`: for copy/move, use `{scope.rootPath}/{TYPE_DIR_MAP[data.type]}/` where TYPE_DIR_MAP is from operationsApi (duplicate the map on client or import).
2. Call the appropriate API function (copyArtifact, moveArtifact, promoteArtifact, demoteArtifact).
3. If result has `conflict: true`:
   - Store pending operation params in state.
   - Show `<ConflictDialog>`. On "Replace File", re-call with `overwrite=true`. On "Keep Original", dismiss.
4. If result has `success: true`:
   - Show toast per UI-SPEC messages:
     - Copy: `"Copied {name} to {projectLabel}"`
     - Move: `"Moved {name} to {projectLabel}. Claude will see this in the next session."`
     - Promote: `"Promoted {name} to Global. Claude will see this in the next session."`
     - Demote: `"Demoted {name} to {projectLabel}. Claude will see this in the next session."`
   - If result has `warnings`, show each as info toast (duration 6000): `warning.message`
   - Call `onRefresh()` to trigger tree re-scan.
5. If result has `error`:
   - Show error toast: `"Failed to {action}: {result.error}. Check terminal for details."` (duration 6000, no auto-dismiss per UI-SPEC).

**Close behavior:** click outside, Esc key, or action selected all close the menu. Attach `useEffect` with document-level click and keydown listeners.

**Viewport edge flipping:** On mount, measure menu element via ref. If `y + menuHeight > window.innerHeight`, set `top = y - menuHeight`. If `x + menuWidth > window.innerWidth`, set `left = x - menuWidth`.
