# Phase 1 — UI Design Contract

> Visual and interaction contract for the Phase 1 status page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 1 UI is a minimal status page only. It shows scan results and a Rescan button. There is no tree view (that is Phase 2). The page must render correctly before `GET /api/scan` completes (loading state) and after it completes (result state).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | none — run `npx shadcn init` at project setup and configure interactively |
| Component library | Radix UI (via shadcn) |
| Icon library | lucide-react (shadcn default) |
| Font | Inter (shadcn default via `@fontsource/inter` or system font stack) |

**shadcn initialization note:** `components.json` does not exist yet. The executor must run `npx shadcn init` as the first client-side setup step. Use React 19 + Vite 8 + Tailwind 4 when prompted.

**Color mode:** Respect `prefers-color-scheme` via shadcn's built-in dark mode support. No manual theme toggle in Phase 1. Both light and dark modes must be correct.

## Color

Use shadcn CSS variables throughout. Do not hardcode hex values in components.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` | Page background |
| Secondary (30%) | `hsl(var(--card))` | Status card surface |
| Accent (10%) | `hsl(var(--primary))` | Rescan button only |
| Destructive | `hsl(var(--destructive))` | Not used in Phase 1 |
| Muted text | `hsl(var(--muted-foreground))` | Secondary labels, artifact type breakdown |

**Accent reserved for:** the Rescan button background and its focus ring. Nothing else in Phase 1 uses the accent/primary color.

Both light and dark token sets are provided by shadcn out of the box. No additional theme customization is required for Phase 1.

## Page Layout

Phase 1 renders a single centered status card. No sidebar, no navigation, no tree.

```
┌─────────────────────────────────────────────────┐
│  [header]  Claude Directory Tree                │
├─────────────────────────────────────────────────┤
│                                                 │
│         ┌──────────────────────────┐            │
│         │  Scan complete.          │            │
│         │  42 artifacts found      │            │
│         │  across 7 projects.      │            │
│         │                          │            │
│         │  [ Rescan ]              │            │
│         └──────────────────────────┘            │
│                                                 │
└─────────────────────────────────────────────────┘
```

- Page: vertically and horizontally centered, full viewport height.
- Header: app name "Claude Directory Tree" top-left, 20px semibold.
- Card: shadcn `<Card>` component, max-width 480px, padding 24px.
- Rescan button: full-width inside the card, shadcn `<Button>` variant `default`.

---

## States

### Loading state (scan in progress)

Shown while `GET /api/scan` has not yet resolved.

- Card displays: "Scanning..." as heading (20px semibold).
- No artifact count visible.
- Rescan button: disabled, label "Scanning..." with a spinner icon (lucide `Loader2`, 16px, animate-spin) to its left.

### Result state (scan complete)

Shown after `GET /api/scan` resolves successfully.

- Card heading: "Scan complete." (20px semibold).
- Body line 1: "{X} artifacts found across {Y} projects." (16px regular). X and Y are injected from the API response (`totalArtifacts` and `scopes.length`).
- Rescan button: enabled, label "Rescan".

### Error state (scan failed)

Shown if `GET /api/scan` returns a non-200 response or network error.

- Card heading: "Scan failed." (20px semibold).
- Body: "Could not read your projects directory. Check that the path exists and try again." (16px regular).
- Rescan button: enabled, label "Rescan".

## Accessibility

- Rescan button must have a visible focus ring (shadcn default provides this).
- During loading, the Rescan button must be `disabled` (not just visually styled as disabled) so keyboard and screen reader users cannot trigger a second scan.
- The `Loader2` spinner must have `aria-hidden="true"` since the button label already conveys state ("Scanning...").
- Color contrast: shadcn's default tokens meet WCAG AA in both light and dark modes. Do not override without re-checking contrast.
