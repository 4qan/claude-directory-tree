## Spacing Scale

Declared values (multiples of 4 only). All tokens map to Tailwind 4 utility classes:

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | p-1 / gap-1 | Icon-to-label gap, inline padding |
| sm | 8px | p-2 / gap-2 | Tree row vertical padding, toolbar inner gap |
| md | 16px | p-4 / gap-4 | Tree indentation per level, toolbar horizontal padding |
| lg | 24px | p-6 / gap-6 | Toolbar outer padding (matches existing App.tsx header p-6) |
| xl | 32px | p-8 / gap-8 | Panel-level breathing room |
| 2xl | 48px | p-12 | Not used in this phase |
| 3xl | 64px | p-16 | Not used in this phase |

Exceptions:
- Tree row height: 28px (not on scale) — standard file-explorer row height; use `h-7` (Tailwind)
- Touch targets: min 44px height on tree items for accessibility; use `min-h-[44px]` on mobile (desktop-primary app, so 28px is acceptable on desktop)
- Tree indentation per depth level: 16px (md token) — each level adds `paddingLeft: level * 16px` via inline style (headless-tree pattern from RESEARCH.md)

## Color

All values are shadcn CSS custom properties from `client/src/App.css`. Supports light and dark mode via `prefers-color-scheme` media query (already configured).

| Role | CSS Variable | Light value | Dark value | Usage |
|------|-------------|-------------|------------|-------|
| Dominant (60%) | `bg-background` | hsl(0 0% 100%) white | hsl(240 10% 3.9%) near-black | App background, tree panel background |
| Secondary (30%) | `bg-muted` | hsl(240 4.8% 95.9%) light gray | hsl(240 3.7% 15.9%) dark gray | Hovered tree row, skeleton shimmer bars, toolbar input background |
| Accent (10%) | `bg-accent` | hsl(240 4.8% 95.9%) | hsl(240 3.7% 15.9%) | Active/selected tree row only |
| Destructive | `bg-destructive` | hsl(0 84.2% 60.2%) red | hsl(0 62.8% 30.6%) dark red | Not used in Phase 2 (no destructive actions) |

Accent reserved for: selected tree row background only. No other element uses `bg-accent` or `text-accent-foreground` in this phase.

Supporting semantic tokens:
- `text-foreground`: primary text (artifact labels, scope names)
- `text-muted-foreground`: secondary text (scope badge "global" / "project", artifact count parenthetical)
- `border`: tree row dividers if needed; toolbar bottom border
- `bg-secondary`: toolbar background to separate it visually from tree

## Interaction Contract

### Expand / Collapse
- Click anywhere on scope or category row to toggle expand/collapse
- Default on load: scopes expanded, categories collapsed (source: CONTEXT.md)
- Chevron rotates 90deg on expand: `transition-transform duration-150`

### Search
- Input in toolbar; debounce 150ms before calling `deriveVisibleTree`
- Live filter: tree re-renders with only matching nodes visible
- Placeholder text: "Search artifacts..."
- Clear: X button appears inside input when query is non-empty; clears query on click

### Type Filter
- shadcn Select dropdown
- Options: "All types" (default) + one option per ArtifactType enum value, human-readable labels
- Label mapping: agent -> "Agents", command -> "Commands", skill -> "Skills", mcp-config -> "MCP Servers", claude-md -> "CLAUDE.md", plugin -> "Plugins", hook -> "Hooks", memory -> "Memory", plan -> "Plan files"
- Selection persists until user changes it

### Refresh
- RefreshCw button at right end of toolbar
- On click: re-fetches `GET /api/scan`; spinner animates during load
- Preserves current expand state across refresh (headless-tree stable dataLoader pattern from RESEARCH.md)
- Button disabled during loading

### No-match State
- Shown when `deriveVisibleTree` returns empty array with active filters
- Inline, centered in tree panel
- Copy: see Copywriting Contract below

### Loading State
- TreeSkeleton with `animate-pulse`: 3 scope rows, each with 2 category placeholder bars
- Skeleton bar sizes: scope rows `h-5 w-32 bg-muted rounded`, category rows `h-4 w-48 bg-muted rounded ml-4`

## Accessibility Contract

Minimum requirements for this phase:

- Tree container: `role="tree"` via headless-tree's `getContainerProps()` — built-in
- Tree items: `role="treeitem"` and `aria-expanded` via headless-tree's `item.getProps()` — built-in
- Refresh button: `aria-label="Refresh artifact tree"` (icon-only button)
- Search input: `<label>` associated via `htmlFor` or `aria-label="Search artifacts"`
- Type filter: `aria-label="Filter by artifact type"` on Select trigger
- Loading: `aria-live="polite"` region in tree panel announces "Loading artifacts..."
- No-match state: rendered in main content flow, not announced aggressively
- Color contrast: shadcn neutral palette passes WCAG AA at default sizes — no override needed
