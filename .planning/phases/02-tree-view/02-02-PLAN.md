    2. Create `client/src/components/tree/ArtifactTree.tsx`:
       - Props interface:
         ```typescript
         interface ArtifactTreeProps {
           scopes: ScopeNode[];
           query: string;
           typeFilter: ArtifactType | null;
           onQueryChange: (q: string) => void;
           onTypeFilterChange: (t: ArtifactType | null) => void;
           onRefresh: () => void;
           isLoading: boolean;
           error: string | null;
         }
         ```
       - Internal logic:
         a. Call `deriveVisibleTree(scopes, query, typeFilter)` to get filtered scopes
         b. Build flat item maps with `useMemo`:
            - Define a union type for tree node data. Three kinds: root node `{ nodeKind: 'root' }`, scope nodes `ScopeNode & { nodeKind: 'scope' }`, category nodes `{ nodeKind: 'category', id: string, type: ArtifactType, children: Artifact[], count: number }`, leaf artifacts `Artifact & { nodeKind: 'leaf' }`
            - `items: Record<string, TreeNodeData>` — flat lookup by ID
            - `children: Record<string, string[]>` — child IDs by parent ID
            - Root has scope IDs as children
            - Each scope has category group IDs as children (generated as `${scope.id}:${artifactType}`)
            - Each category has its artifact IDs as children
            - Plugins with children: their child artifacts are children of the plugin node
            - Memoize with `[filteredScopes]` dependency
         c. Wire `useTree` from @headless-tree/react:
            ```typescript
            const tree = useTree<TreeNodeData>({
              rootItemId: 'root',
              getItemName: (item) => {
                const d = item.getItemData();
                if (d.nodeKind === 'scope') return d.label;
                if (d.nodeKind === 'category') return TYPE_LABELS[d.type];
                if (d.nodeKind === 'leaf') return d.name;
                return 'root';
              },
              isItemFolder: (item) => item.getItemData().nodeKind !== 'leaf',
              dataLoader: syncDataLoaderFeature.createStaticDataLoader(items, children),
              // OR use manual dataLoader if static helper unavailable:
              // dataLoader: { getItem: (id) => items[id], getChildren: (id) => children[id] ?? [] },
              initialState: { expandedItems: filteredScopes.map(s => s.id) },
              features: [syncDataLoaderFeature],
            });
            ```
            IMPORTANT: Memoize the dataLoader to prevent expand state reset on re-render (see RESEARCH.md anti-pattern).
         d. Render:
            - TreeToolbar at top
            - If isLoading and scopes is empty: render TreeSkeleton
            - If error: render error state (heading "Could not load artifacts", body "Failed to scan directory. Check that the path exists and try again.", Button "Try again" calling onRefresh)
            - If filteredScopes is empty and (query or typeFilter is active): render no-match state ("No matching artifacts" / "No artifacts matching your filters." / Button "Clear filters")
            - If filteredScopes is empty and no filters: render empty state ("No Claude artifacts found" / guidance text)
            - Otherwise: render tree container with `tree.getContainerProps()` and `className="flex-1 overflow-y-auto px-2 py-2 outline-none"`, map `tree.getItems()` with TreeItem, each wrapped in div with `style={{ paddingLeft: item.getItemMeta().level * 16 }}` and spread `item.getProps()`
