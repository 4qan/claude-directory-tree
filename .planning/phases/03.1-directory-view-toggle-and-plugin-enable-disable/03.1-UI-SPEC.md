## New Component Specifications

### View Toggle Button

Location: Tree bar row (`ArtifactTree.tsx` lines 506-517), between "Collapse all" and scope count.

Anatomy:
```
[ Collapse all ]   [ flat-icon | hierarchy-icon ]   2 scopes
```

- Render as a two-segment icon toggle (not a text toggle).
- Flat view icon: `List` (lucide) — represents scope-grouped list.
- Directory view icon: `FolderTree` (lucide) — represents filesystem hierarchy.
- Active segment: `text-foreground bg-muted rounded-sm` at `p-1`.
- Inactive segment: `text-muted-foreground hover:text-foreground` at `p-1`.
- Wrapper: `flex items-center gap-0.5` with a `rounded-sm border border-border` container.
- Total touch target: min 28px height (matches `h-7` row height).
- aria-label on each button: `"Flat view"` / `"Directory view"`.
- aria-pressed: `true` on active segment.

### Folder Node (directory view only)

New `nodeKind: 'folder'` for non-Claude ancestor directories.

Anatomy:
```
  [chevron]  [Folder icon]  folder-name
```

- Row height: `h-7` — consistent with scope/category rows.
- Padding: `px-2 py-1` — consistent.
- Chevron: `ChevronRight` size 16, rotates 90deg when expanded — same as scope/category pattern.
- Folder icon: `Folder` (lucide) size 16, `text-muted-foreground shrink-0` — muted to visually de-emphasize non-Claude directories.
- Label: `text-sm font-normal` — lower weight than scope (`font-semibold`), signals these are path nodes not scopes.
- No artifact count badge.
- No context menu action on folder nodes.
- Hover: `hover:bg-muted/50` — slightly lighter than scope hover to further de-emphasize.

### Current Project Badge (directory view only)

Appended after project folder name in directory view.

- Badge: `bg-blue-100 text-blue-700 dark:bg-blue-900 dark:text-blue-300`
- Text: `"current"`
- Size: `text-[10px] font-normal px-1.5 py-0.5 rounded-full leading-none shrink-0`

Note: `px-1.5 py-0.5` is the existing badge padding class carried from the codebase. It is not a declared spacing token. `font-normal` (400) used here, consistent with the badge typography role.

### Plugin Enable/Disable Action

**Context menu:** Inserted as first action for `plugin` leaf nodes, before "Open in Editor".
- When enabled: label `"Disable plugin"`, icon `ToggleLeft` (lucide) size 16.
- When disabled: label `"Enable plugin"`, icon `ToggleRight` (lucide) size 16.
- Only rendered when `data.enabled !== undefined` (settings.json has enabledPlugins field).
- Style: same as existing context menu items — `flex items-center gap-2 px-3 py-1.5 text-sm`.
- No destructive styling — this is a toggle, not a removal.

**Detail panel:** Rendered as a `Button variant="outline" size="sm"` action alongside existing actions.
- When enabled: label `"Disable"`, icon `ToggleLeft` size 14.
- When disabled: label `"Enable"`, icon `ToggleRight` size 14.
- Only rendered when `artifact.enabled !== undefined`.

## Interaction States

### View toggle switching
1. User clicks the inactive toggle segment.
2. Toggle segment updates immediately (no loading state).
3. Tree re-renders with new view structure.
4. Expansion state resets: flat view resets to scopes expanded/categories collapsed; directory view resets to top-level expanded/rest collapsed.
5. No toast — view switch is reversible and low-stakes.
6. Preference written to `localStorage` key `cdt_view_mode` as `"flat"` or `"directory"`.

### Plugin enable/disable
1. User triggers action (context menu or detail panel button).
2. Button/menu item shows no intermediate loading state — action is fast (file write).
3. After success: `showToast('Plugin enabled', 'success')` or `showToast('Plugin disabled', 'success')`.
4. Full tree refresh triggered after toast.
5. If error: `showToast('Failed to update plugin: {error}', 'error', 6000)`.
6. No confirmation dialog — toggle is reversible.

### Directory view search/filter
- Filter behaves identically to flat view.
- Ancestor folder nodes are preserved in results to provide path context (never hidden when a descendant matches).
- No visible change to toolbar — same search + type filter controls.

## Copywriting Contract

| Element | Copy |
|---------|------|
| View toggle: flat | aria-label: `"Flat view"` |
| View toggle: directory | aria-label: `"Directory view"` |
| Plugin enable action | `"Enable plugin"` (context menu), `"Enable"` (detail panel button) |
| Plugin disable action | `"Disable plugin"` (context menu), `"Disable"` (detail panel button) |
| Plugin enabled toast | `"Plugin enabled"` |
| Plugin disabled toast | `"Plugin disabled"` |
| Plugin toggle error | `"Failed to update plugin: {error}"` |
| Current project badge | `"current"` |
| No plugins with toggle (settings absent) | Action not shown — no error message |

Empty states: No new empty states in this phase. Existing empty state copy unchanged:
- No artifacts: `"No Claude artifacts found"` + `"No Claude artifacts found in the scanned directory. Check your scan path or add projects manually."`
- No match: `"No matching artifacts"` + `"No artifacts matching your filters."` + `"Clear filters"` button

Error state: No new error states beyond the existing `"Could not load artifacts"` flow. Plugin toggle errors surface via existing `showToast` with `error` variant.

Destructive actions: None in this phase. Plugin enable/disable is reversible; no confirmation required.
