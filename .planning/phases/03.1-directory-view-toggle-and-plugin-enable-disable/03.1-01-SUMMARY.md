## Decisions Made

- Common ancestor computation uses project directories (parent of `.claude/`) not rootPaths directly. This ensures that for a single-project case, the tree starts at the project directory rather than its `.claude/` subdirectory.
- Scope nodes are preserved in the items map by their original id even in directory view. This lets Plan 02 (UI wiring) access scope labels and rootPaths for badge rendering without additional lookup.

## Deviations from Plan

None — plan executed exactly as written. The single-project ancestor edge case was caught during TDD (Test 8 failed on first implementation) and fixed before the GREEN phase commit.

## Issues Encountered

Test 8 ("single project starts at project directory") initially failed because `commonAncestor(['rootPath'])` returns the rootPath itself (the `.claude/` dir), resulting in zero `segmentsAfterAncestor`. Fix: compute common ancestor across project directories (parent of `.claude/`) rather than rootPaths. Diagnosed and fixed in one iteration.
