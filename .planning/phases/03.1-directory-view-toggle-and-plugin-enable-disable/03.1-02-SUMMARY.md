## Decisions Made

- Section headers only in flat view — they are redundant in directory view where filesystem hierarchy communicates the same structure
- Current badge added unconditionally on scope nodes when `data.section === 'current'` rather than gating on view mode — provides signal in both views with no downside
- localStorage read in useState initializer function (not useEffect) to avoid flash of wrong view on first render
